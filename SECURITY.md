# Security

## Reporting a problem

If you find a security problem in the Kairo skill or in the dashboard at kairo.rohansurve.in, please **email rohan.surve5@gmail.com** with the subject "Kairo security". Do not open a public issue.

Please include:

- what you found and where (file, page or connector tool);
- the steps to see it;
- what someone could do with it.

Please don't access other people's data, run load tests or attack the live site to prove a point. A clear description is enough.

You'll get a reply as soon as possible. Once the problem is fixed, you can be credited in the [CHANGELOG](CHANGELOG.md) if you want to be.

## Supported versions

Only the latest release is supported.
