# Country CV formats

The build script applies the header lines and extras below from `cv.json` `country`. All CVs: A4, one column, real selectable text, dates as in my-facts (MM/YYYY), 1 to 2 pages.

"Abroad" means the job country is not the user's home country. "Check current advice" means local norms change: tell the user it is optional and let them decide.

At home (job country = home country): location line is the city and country only. If the job is in another city, the relocation line goes in the cover letter, not on the CV.

## Notes the build script follows

- **Visa line** appears only when `personal.needs_visa` is true for that country (the truth check compares it with my-facts).
- **Nationality** appears only abroad, and not for the UK.
- **Photo and date of birth:** off by default. Switch on only when the user asks: `options.include_photo: true` plus `personal.photo` (path to the image the user uploaded), or `options.include_dob: true` plus `personal.date_of_birth`. The truth check fails if they are switched on for a country where they are not allowed (photo only DE, FR, AE; date of birth only DE, AE), and the date of birth must match my-facts. The photo goes top right on page 1.
- **Germany** languages without a CEFR level make the truth check fail: ask the user for levels and add them to my-facts.
- **Poland** clause text: "I hereby consent to the processing of my personal data by <Company> for the purposes of the current recruitment process, in accordance with Regulation (EU) 2016/679 (GDPR)."

## File names

`<First>_<Last>_CV_<Company>.pdf` and `<First>_<Last>_Cover_Letter_<Company>.pdf`. No spaces. The PDF title metadata matches the file name; the author is the user.
